# Witness Hamiltonians

Numerical witnesses certifying that the local commutator matrix `C(h)` attains
maximal rank `|U_c| - 1` for various Hamiltonian families. One witness certifies
the generic statement because the rank condition is Zariski-open.

## Layout

```
witness_hamiltonians/
├── README.md
├── run_witness.py            driver: job catalog and backend dispatch
├── consolidate.py            print coverage summary
├── witness_structured.py      graphs, families, dense rank backend
├── additional_runs.py         sparse/iterative Gram backend
├── periodic/                  periodic-boundary checked results
│   ├── dense/
│   ├── xyz/
│   └── full_nn_2body_all_fields/
└── open_boundary/             open-boundary checked results
    ├── dense/
    ├── xyz/
    └── full_nn_2body_all_fields/
```

Open-boundary jobs are generated by exact rooted local-patch isomorphism: each
entry certifies one representative root and records how many finite-lattice roots
it covers. This is what checks boundary, near-boundary, corner/edge/face, and
bulk environments without rerunning isomorphic copies.

For open-boundary jobs, `local_mode = formal_uc` uses the local coordinate set
from the proof:

```
U_c = {u in V_{k,R}: supp(P_u) intersects B(c,R)}.
```

This is larger than the older rooted-ball convention because it keeps the full
support of every term intersecting the root ball. Representatives are therefore
classified by rooted radius-`2R` environments. Existing periodic files are kept
in their historical `rooted_ball` mode unless rerun.

## Reproducing

Use a Python environment with `numpy`, `scipy`, and `networkx`.

```
python run_witness.py --boundary periodic --dry-run
python run_witness.py --boundary open_boundary --dry-run --estimate
python run_witness.py --boundary open_boundary --families dense
python run_witness.py --boundary open_boundary --families xyz full_nn_2body_all_fields
python run_witness.py --boundary all --memory-cap-gb 16
python consolidate.py
```

Backend dispatch is currently `|U_c| <= 1000` to the dense backend and larger
families to the sparse backend. Sparse jobs with larger Gram matrices use an
iterative smallest-eigenvalue check on `C(h)^* C(h)` after lifting the known
Hamiltonian null vector.

For formal open-boundary dense jobs, the witness vector is restricted to terms
of Pauli weight at most 2. This still certifies the full dense `U_c` when the
rank reaches `|U_c| - 1`, but it avoids enumerating all dense `U_c x U_c`
commutator pairs.
